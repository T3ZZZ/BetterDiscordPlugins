A collection of BetterDiscord plugins I originally made for myself and my friends back in the day. Unfortunately, they had become outdated, but thanks to A.I, I was able to restore a few of them. So I’m posting them here in the hope that they can be useful to the community.

BetterInbox.plugin.js: A plugin that actually makes Discord's inbox useful by showing messages you haven't replied to that are relevant to you. This includes DMs, server messages replying to one of your messages, and server messages where you were mentioned, excluding @everyone and @here.

MessagePurger.plugin.js: A plugin that adds a small trash can icon in the top-right corner of your conversation. Clicking it lets you delete as many messages as you want, with a customizable delay between each deletion.

RecentlyVisitedChannels.plugin.js: A plugin that lets you quickly access channels and conversations you've visited recently using CTRL + SHIFT + H. You can change the shortcut in the plugin settings.

UnansweredTimer.plugin.js: A plugin that shows how long you've gone without replying to a message, as well as how long the other person took to write it. It's pretty useless, but hey, it was one of my first plugins back in 2022 haha.
